# MarketCalc

**MarketCalc** — простой веб-калькулятор для расчёта стоимости товаров в игре [Supermarket Together](https://store.steampowered.com/app/2709570/Supermarket_Together/).

Калькулятор помогает быстро определить цену продажи товара на основе закупочной стоимости и выбранного процента наценки.

### 🌐 Демо-версия

[Открыть MarketCalc](https://med1ocre-programmer.github.io/MarketCalc/)

## ✨ Возможности

- **Наценка по умолчанию — 99%.** Можно установить собственное значение.
- **Мгновенный расчёт** стоимости товара.
- **Поддержка десятичных чисел** с запятой и точкой.
- **Корректное округление** до двух знаков после запятой (ROUND_HALF_UP).
- **Копирование результата** в буфер обмена одним нажатием.
- **Адаптивный интерфейс** для компьютеров, смартфонов и планшетов.
- **AMOLED-тема** с глубоким чёрным фоном.
- **Поддержка PWA** — возможность установить калькулятор на главный экран устройства.
- **Конфиденциальность.** Все вычисления выполняются непосредственно в браузере. Данные пользователя никуда не отправляются.

## 🚀 Как пользоваться

1. Откройте [MarketCalc](https://med1ocre-programmer.github.io/MarketCalc/).
2. Укажите процент наценки или оставьте значение по умолчанию — 99%.
3. Введите закупочную стоимость товара.
4. Нажмите кнопку расчёта.
5. Получите готовую цену продажи и при необходимости скопируйте её.

## 📱 Установка на смартфон

MarketCalc поддерживает установку в качестве PWA (Progressive Web App). После установки калькулятор можно запускать с главного экрана, практически как обычное приложение.

### Android

1. Откройте [MarketCalc](https://med1ocre-programmer.github.io/MarketCalc/) в Google Chrome.
2. Нажмите на меню с тремя точками.
3. Выберите «Установить приложение».
4. Подтвердите установку.

### iOS / iPadOS

1. Откройте [MarketCalc](https://med1ocre-programmer.github.io/MarketCalc/) в Safari.
2. Нажмите кнопку «Поделиться».
3. Выберите «На экран Домой».
4. При необходимости включите параметр «Открывать как веб-приложение».
5. Нажмите «Добавить».

## 🔒 Конфиденциальность

MarketCalc не требует регистрации и не собирает персональные данные.

Все расчёты выполняются локально в браузере. Введённые значения не передаются на сторонние серверы.
